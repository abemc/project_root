# AI リスク評価チェックリスト

このチェックリストは、ML プロジェクトのデータ処理・モデル開発・デプロイの各フェーズにおけるリスクを体系的に評価するためのものです。

---

## フェーズ 1: データ収集・前処理

### プライバシーとコンプライアンス

- [ ] 個人情報保護法 / GDPR / 業界規制への準拠を確認した
- [ ] データ収集の法的根拠（同意・契約・正当な利益など）を明確にした
- [ ] 目的外のデータ利用が発生していないことを確認した
- [ ] データ保持期間と削除ポリシーを設定した
- [ ] 直接識別子（氏名・住所など）をモデル訓練に使用していない

### データ品質とバイアス

- [ ] 訓練データが対象母集団を十分に代表しているか確認した
- [ ] データ収集期間に偏りがないか確認した（季節性・イベントなど）
- [ ] 欠損値・外れ値の処理方針を記録した
- [ ] ラベルの品質を検証した（複数アノテーター・合意率など）
- [ ] 保護属性（性別・年齢・人種など）を特徴量として使用していない、または使用の正当性を文書化した

---

## フェーズ 2: モデル開発・評価

### 公平性評価

- [ ] 人口統計グループ別の精度・False Positive Rate を比較した
- [ ] 公平性指標（Equal Opportunity, Demographic Parity 等）を計算した
- [ ] グループ間の性能差が許容範囲内であることを確認した
- [ ] スライス分析（サブグループ別評価）を実施した

### 堅牢性・安全性

- [ ] 分布外サンプルに対するモデルの挙動を確認した
- [ ] 敵対的入力に対する耐性を評価した（分類モデルの場合）
- [ ] 極端な入力値・欠損値に対してクラッシュしないことを確認した
- [ ] モデルの予測不確実性を推定する手段がある（予測区間・確信度など）

### 説明可能性

- [ ] 特徴量重要度または SHAP 値を計算した
- [ ] モデルの決定に影響を与える主要な特徴量を特定した
- [ ] 高リスクな意思決定（医療・金融・採用など）には説明可能なモデルを選択した
- [ ] ユーザーへの説明フォーマットを設計した

---

## フェーズ 3: デプロイ・運用

### セキュリティ

- [ ] API エンドポイントに認証・認可を実装した
- [ ] 入力データのバリデーションを実装した（型・範囲・長さ）
- [ ] 機密情報（API キー・個人情報）をレスポンスに含めていない
- [ ] ログに個人情報を記録していない
- [ ] レート制限を設定した

### モニタリングと監視

- [ ] 予測ログを構造化された形式で記録している
- [ ] データドリフトの自動検出を設定した
- [ ] モデル性能の定期的な再評価スケジュールを設定した
- [ ] 異常な予測パターンへのアラートを設定した
- [ ] モデルのリタイアメント基準を定義した

### ガバナンス

- [ ] モデルカードまたはデータシートを作成した
- [ ] 利用目的と禁止事項を文書化した
- [ ] ユーザーからの苦情・異議申し立ての対応フローを設計した
- [ ] Human-in-the-loop（人間による最終確認）が必要な場面を特定した
- [ ] インシデント対応プランを策定した

---

## フェーズ 4: 廃止・データ削除

- [ ] ユーザーデータの削除リクエストに対応できる仕組みがある
- [ ] モデルの廃止計画と代替移行フローがある
- [ ] モデルファイルと訓練データの安全な削除手順を定義した
