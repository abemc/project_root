## 演習 4 — 主成分分析 (PCA) の実装

**目標**: NumPy だけを使って PCA を手実装する。

```python
# 2D データの生成（相関あり）
np.random.seed(42)
x = np.random.randn(100)
y = 0.8 * x + 0.2 * np.random.randn(100)
X = np.column_stack([x, y])   # shape: (100, 2)
```

手順:
1. データを標準化（平均 0、標準偏差 1）する
2. 共分散行列 $\Sigma$ を計算する
3. $\Sigma$ の固有値・固有ベクトルを求める
4. 固有値の大きい順に並べ替え、第 1 主成分と第 2 主成分を取得する
5. データを主成分空間に射影する
6. 散布図で元データと主成分軸を描画する

検証: `sklearn.decomposition.PCA` と結果を比較する
